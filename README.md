# Machine Learning Projects Portfolio

A collection of five end-to-end Machine Learning projects covering Regression, Classification, Customer Analytics, Clustering, and Natural Language Processing (NLP).

## Projects

| # | Project | Machine Learning Task | Description |
|---|---|---|---|
| 01 | [House Price Prediction](./01-House-Price-Prediction/) | Regression | Predict house prices based on property characteristics. |
| 02 | [Classification Project](./02-Classification-Project/) | Classification | Train and compare multiple classification algorithms. |
| 03 | [Customer Churn Prediction](./03-Customer-Churn-Prediction/) | Classification | Predict whether customers are likely to leave a service. |
| 04 | [Customer Segmentation](./04-Customer-Segmentation/) | Clustering | Discover customer groups using K-Means. |
| 05 | [Sentiment Analysis](./05-Sentiment-Analysis/) | NLP | Classify text sentiment as positive or negative. |

6. Feature Engineering
7. Model Training
8. Model Comparison

10. Best Model Selection
11. Model Saving
12. Prediction on New Data
13. Streamlit Deployment

## Installation

Clone the repository:

```bash
git clone <repository-url>
cd ML-Portfolio
```

Navigate to any project folder:

```bash
cd 01-House-Price-Prediction
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the Jupyter Notebook:

```bash
jupyter notebook notebook.ipynb
```

Run the Streamlit application:

```bash
streamlit run app.py
```

## Model Evaluation

Different evaluation metrics are used depending on the project:

- Regression: MAE, MSE, RMSE, R².
- Classification: Accuracy, Precision, Recall, F1-Score.
- Clustering: Silhouette Score.
- NLP: Accuracy, Precision, Recall, F1-Score.
